# התקנת האפליקציה בטלפון (Android) — מדריך שלב-שלב

האפליקציה היא **PWA**: אחרי שמעלים אותה פעם אחת לאינטרנט (חינם), מתקינים אותה בטלפון כמו אפליקציה רגילה — אייקון במסך הבית, מסך מלא, **עובדת גם בלי אינטרנט**, בלי שום התחברות. כל הנתונים נשמרים על הטלפון.

התיקייה שצריך להעלות: `c:\מילים לפסיכומטרי\app`
(הקבצים: `index.html`, `words.js`, `sw.js`, `manifest.webmanifest`, והתיקיות `lib` ו-`icons`.)

---

## חלק א' — העלאה ל-GitHub Pages (פעם אחת)

### 1. פתיחת חשבון GitHub (חינם)
- נכנסים ל-https://github.com → **Sign up**. ממלאים אימייל, סיסמה, שם משתמש. מאשרים את האימייל.

### 2. יצירת מאגר (repository)
- לוחצים על **+** למעלה מימין → **New repository**.
- **Repository name**: למשל `milim` (אותיות באנגלית).
- מסמנים **Public**.
- לוחצים **Create repository**.

### 3. העלאת הקבצים
- במסך המאגר החדש לוחצים על הקישור **uploading an existing file** (או **Add file → Upload files**).
- פותחים את התיקייה `c:\מילים לפסיכומטרי\app` במחשב, **בוחרים את כל מה שבתוכה** (index.html, words.js, sw.js, manifest.webmanifest, וגם התיקיות lib ו-icons) **וגוררים** לתוך החלון של GitHub.
  > חשוב: לגרור את **התוכן** של תיקיית `app`, לא את התיקייה עצמה — כך ש-`index.html` יהיה בשורש המאגר.
- למטה לוחצים **Commit changes**.

### 4. הפעלת Pages
- בתוך המאגר: **Settings** (למעלה) → בתפריט הצד **Pages**.
- תחת **Branch** בוחרים `main` ואז `/ (root)` → **Save**.
- ממתינים כדקה. בראש העמוד יופיע הקישור, בסגנון:
  **`https://<שם-המשתמש>.github.io/milim/`**
- זה הקישור הקבוע שלך. פותחים אותו פעם אחת במחשב כדי לוודא שהכול עובד.

---

## חלק ב' — התקנה בטלפון (Chrome / Android)

1. פותחים את הקישור `https://<שם-המשתמש>.github.io/milim/` ב-**Chrome** בטלפון.
2. פותחים את תפריט שלוש-הנקודות (⋮) למעלה.
3. בוחרים **«התקן אפליקציה»** או **«הוסף למסך הבית»**.
4. מאשרים. יופיע אייקון חדש במסך הבית — פותחים אותו, והאפליקציה נפתחת במסך מלא כמו אפליקציה רגילה.
5. אחרי הפתיחה הראשונה (עם אינטרנט), האפליקציה נטענת למכשיר ו**תעבוד גם במצב טיסה / בלי אינטרנט**.

---

## גיבוי והעברת נתונים
- הנתונים (יודע/לא יודע/נבדק, קבוצות, תיקונים) נשמרים **על המכשיר בלבד**.
- כדי לשמור עותק או להעביר למכשיר אחר: בתוך האפליקציה → ⚙ (למעלה משמאל) → **גיבוי — הורדת קובץ**. בקובץ הזה אפשר **שחזור** באותו מסך במכשיר אחר.

## עדכון האפליקציה בעתיד
- אם נרצה לשנות משהו, פשוט מעלים מחדש את הקבצים שהשתנו (Add file → Upload files → Commit). האפליקציה בטלפון תתעדכן לבד בפתיחה הבאה עם אינטרנט.
